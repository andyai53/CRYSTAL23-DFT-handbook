# Band structure

_Estimated time: 40 minutes | Difficulty: Intermediate | Status: planned_

---

This page will show how to select and document a high-symmetry path for bulk and two-dimensional models, how to check the resulting labels, and how to avoid treating a visually plausible plot as proof that the path is correct.

## Planned learning goals

- Distinguish a reciprocal-space path from a DOS k-point mesh
- Explain why bulk and slab paths can differ
- Record the path, number of points and energy reference with every figure
- Check metallic or gapped behaviour without overinterpreting one line cut

The worked path examples will be added after the target CRYSTAL23 version and the group-approved reciprocal-space conventions have been fixed.
