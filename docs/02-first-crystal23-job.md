# Your first CRYSTAL23 job

_Estimated time: 45 minutes | Difficulty: Beginner | Status: planned_

---

This page will use a small, supervisor-approved training system to demonstrate a complete first run. It will not use a production Ti2C or Ti3C2 model: the first lesson should make it easy to distinguish a software or scheduler problem from a materials-model problem.

## Planned learning goals

- Copy a known-good input without editing the source example
- Submit one job through PBS
- Follow the output while the job runs
- Locate the final SCF energy and convergence message
- Record the run in a calculation passport

## Planned checkpoint

The student will be able to answer all four questions before continuing:

1. Which input file was submitted?
2. Which PBS job ID ran it?
3. Where is the explicit SCF-convergence message?
4. Which files must be retained to reproduce the run?

The executable example will be added after a validated small CRYSTAL23 input and the local PBS resource template have been selected. This placeholder is intentional: a tutorial should never present an untested input as a first-job example.
